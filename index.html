The short version

I'm Aryan. I like building things that react to the people using them, which is a polite way of saying I got hooked on the moment an interface does something you did not expect and it still feels obvious.

I started at the front end because I wanted to control how something feels, not only whether it works. That pulled me through the rest of the stack. At SDSLabs I have been shipping across it since February 2025, and at Tinkering Labs I write software for drones, motion sensors and AR/VR rigs.

Hackathons are where I test speed. I have won a few, lost more, and learned that a working demo beats a perfect plan. Away from the keyboard it is guitar, keyboard, and sport.

Make it work. Then make it feel like it was always supposed to work that way.
